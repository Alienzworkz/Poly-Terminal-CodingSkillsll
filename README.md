# Decentralized Trading Terminal

A C++ terminal-based trading application demonstrating core computer science algorithms (Greedy & Dynamic Programming) and blockchain fundamentals. 

## 🚀 Features
- **Real-time Trading Engine**: Place buy/sell orders, view order books with depth of market, and track portfolios with P&L.
- **Algorithm Demonstrations**: Features implementations of **Greedy algorithms** (best execution price selection) and **Dynamic Programming** (portfolio optimization/Knapsack).
- **Blockchain Integration**: Immutable trade recording via Proof-of-Work mining (SHA-256) and a built-in block explorer.
- **Interactive TUI**: A clean terminal user interface with ANSI colors and real-time updates.

## 🛠️ Tech Stack
- **Language**: C++17
- **Dependencies**: OpenSSL (libcrypto, libssl)
- **Build**: Makefile / Shell & Batch scripts
