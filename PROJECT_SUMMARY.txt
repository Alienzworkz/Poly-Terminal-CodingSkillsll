TROUBLESHOOTING
---------------
Issue: Build fails
Fix:   Install g++ and OpenSSL, check PATH

Issue: Order not matching
Fix:   Check price crosses spread (buy >= ask, sell <= bid)

Issue: Blockchain not updating
Fix:   Remember to mine pending trades (option 6)
