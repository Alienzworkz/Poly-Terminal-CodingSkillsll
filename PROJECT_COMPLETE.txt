================================================================================
                         TROUBLESHOOTING
================================================================================

BUILD ISSUES:
  Problem: Compiler not found
  Solution: Install g++ or MinGW-w64

  Problem: OpenSSL not found
  Solution: Install OpenSSL library
    Windows: https://slproweb.com/products/Win32OpenSSL.html
    Linux:   sudo apt-get install libssl-dev
    Mac:     brew install openssl

RUNTIME ISSUES:
  Problem: Order not matching
  Solution: Check price crosses spread (buy >= ask, sell <= bid)

  Problem: Blockchain not updating
  Solution: Remember to mine pending trades (menu option 6)

GIT ISSUES:
  Problem: Permission denied
  Solution: Use HTTPS URL instead of SSH

  Problem: Repository not found
  Solution: Verify repository URL is correct
